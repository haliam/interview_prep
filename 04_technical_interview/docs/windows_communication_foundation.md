# Windows Communication Foundation (WCF)

> **Purpose:** WCF interview reference — services, endpoints, messages, addresses, and attributes.

## WCF

> "Windows Communication Foundation (WCF) is a runtime and a set of APIs for creating systems that send messages between services and clients."
>
> "Also used to create applications that communicate with other applications on the same computer system, or on a system that resides in another company and is accessed over the Internet."

---

## Endpoint

> "Place where messages are sent or received (or both), and they define all the information required for the message exchange."

It comprises an address, a binding, and a service contract.

---

## Message

> "A self-contained unit of data that can consist of several parts, including a body and headers."

---

## Service

> "A construct that exposes one or more endpoints, with each endpoint exposing one or more service operations."

---

## Address

- Specifies the location where messages are received.
- It is specified as a Uniform Resource Identifier (URI).

---
