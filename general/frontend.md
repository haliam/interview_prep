## DOM

> "A programming interface for HTML and XML documents. It provides a structured representation of the document and defines how programs can access it in order to modify its structure, style, and content."
>
> "The *DOM* (Document Object Model) is an [API](https://developer.mozilla.org/es/docs/Glossary/API) defined to represent and interact with any [HTML](https://developer.mozilla.org/es/docs/Glossary/HTML) or [XML](https://developer.mozilla.org/es/docs/Glossary/XML) document."
>
> "The **Document Object Model** (**DOM**) is a [cross-platform](https://en.wikipedia.org/wiki/Cross-platform) and [language-independent](https://en.wikipedia.org/wiki/Language-independent_specification) interface that treats an [XML](https://en.wikipedia.org/wiki/XML) or [HTML](https://en.wikipedia.org/wiki/HTML) document as a [tree structure](https://en.wikipedia.org/wiki/Tree_structure) wherein each [node](https://en.wikipedia.org/wiki/Node_(computer_science)) is an [object](https://en.wikipedia.org/wiki/Object_(computer_science)) representing a part of the document."

## AJAX

> "AJAX (from the English initials **A**synchronous [JavaScript](https://developer.mozilla.org/es/docs/Glossary/JavaScript) **A**nd [XML](https://developer.mozilla.org/es/docs/Glossary/XML)) is a programming practice used to build more complex and dynamic web pages, using a technology known as [XMLHttpRequest](https://developer.mozilla.org/en-US/docs/Glossary/XHR_(XMLHttpRequest))."
>
> "What AJAX allows us to do is modify specific parts of the [DOM](https://developer.mozilla.org/es/docs/Glossary/DOM) of an [HTML](https://developer.mozilla.org/es/docs/Glossary/HTML) page without needing to refresh the whole page. AJAX also allows us to work asynchronously; this means your code will keep running while that part of your site's page tries to reload."

### Kendo UI

> "Kendo UI is an HTML5, jQuery-based framework for building modern HTML apps. Kendo UI combines the best of emerging HTML5, CSS3, and JavaScript technologies. Kendo UI combines everything that a developer needs to build a rich JavaScript app."
>
> "Kendo UI is a pure JavaScript framework, so using Kendo UI is as simple as referencing JavaScript and CSS resources on your page."

### Kendo UI Widgets

Kendo UI widgets are part of the Kendo UI Framework. Kendo UI widgets are grouped into three collections:

- Kendo UI Web for touch-enabled desktop development.
- Kendo UI DataViz for desktop and mobile data visualizations.
- Kendo UI Mobile for mobile app development, including PhoneGap deployment.

All widgets complement the tooling you need for modern HTML5 and JavaScript development.

### Kendo UI vs UI for ASP.NET MVC

> "Kendo UI is a JavaScript library for developing rich client-side web applications, with various dynamic jQuery-based user interfaces."
